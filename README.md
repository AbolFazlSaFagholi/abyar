# تیپ‌آگرو — نسخه نمایشی GitHub Pages

این پروژه یک دموی استاتیک و راست‌چین از فروشگاه تجهیزات آبیاری است و برای GitHub Pages آماده شده است.

## امکانات
- طراحی واکنش‌گرا برای موبایل و دسکتاپ
- نمایش نمونه محصولات
- جستجو و فیلتر دسته‌بندی
- سبد خرید نمایشی با ذخیره در `localStorage`
- فرم عضویت نمایشی
- بدون PHP، سرور یا پایگاه داده

## انتشار روی GitHub Pages
1. این فایل‌ها را در ریشه یک مخزن GitHub آپلود کنید: `index.html`, `style.css`, `script.js`, `README.md`.
2. در مخزن به **Settings → Pages** بروید.
3. در بخش **Build and deployment** گزینه **Deploy from a branch** را انتخاب کنید.
4. Branch را روی `main` و پوشه را روی `/(root)` بگذارید و **Save** کنید.
5. چند دقیقه صبر کنید؛ لینک سایت در همان صفحه Pages نمایش داده می‌شود.

## محدودیت‌ها
- محصولات نمونه‌اند و داده‌های واقعی فروشگاه نیستند.
- سبد خرید فقط روی همان مرورگر/دستگاه ذخیره می‌شود.
- پرداخت، ورود کاربران، مدیریت محصولات و ثبت سفارش واقعی وجود ندارد.
- فونت Vazirmatn از Google Fonts بارگیری می‌شود؛ در صورت نبود اینترنت از فونت جایگزین استفاده می‌شود.
